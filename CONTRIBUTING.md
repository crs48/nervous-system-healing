# Contributing

Nervous System Healing is a free, open-source community resource maintained by
Christopher Smothers. Corrections, accessibility improvements, clearer writing,
research updates, and thoughtful design contributions are welcome.

## Suggest something

Open an [issue](https://github.com/crs48/nervous-system-healing/issues) with the
page or feature, what could improve, and a proposed change. For broken links,
include the destination. For research updates, link the original study or
guideline and explain which claim it affects.

Issues and pull requests are public. Please avoid posting personal medical
histories or identifying information about someone else. You can describe a
usability problem without sharing a personal story.

## Make a change

1. Fork the repository and create a branch for one focused change.
2. Follow the setup in [README.md](README.md) and read
   [CONTENT_GUIDELINES.md](CONTENT_GUIDELINES.md). The latest
   [overhaul exploration](docs/explorations/0010_%5B_%5D_A_LITTLE_MORE_ROOM_NERVOUS_SYSTEM_SITE_REJUVENATION.md)
   identifies proposed updates to those guidelines; flag conflicts in your PR.
3. Keep health claims specific to the population, intervention, and outcome
   studied. Separate evidence, teaching frameworks, and personal experience.
   Avoid universal safety claims, diagnoses from website inputs, and promises
   of a permanent reset.
4. Preserve choice, readable language, keyboard access, and the option to stop.
   For visual changes, check narrow screens and reduced-motion preferences.
5. Run `npm run build`. Explain what you changed and how you checked it in a
   pull request; include a screenshot for a visible change.

Small contributions are welcome. Larger changes are easier to coordinate with
an issue first. Clinical content may need subject-matter review before merging.
